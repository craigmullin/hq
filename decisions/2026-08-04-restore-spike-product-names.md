# Restore SpikeChat and SpikeStat product identities

Date: 2026-08-04

Status: approved and implemented

## Decision

SpikeChat and SpikeStat are the canonical product names. Their GitHub
repositories use `craigmullin/spikechat` and `craigmullin/spikestat`.

Existing Firebase project identifiers, browser-storage keys, application
routes, and preserved legacy paths remain unchanged when renaming them would
break deployment, stored data, links, or historical traceability. Those
technical identifiers do not define the public product names.

## Scope

Apply the restored names to product interfaces, PWA metadata, legal and product
copy, Design guidance, CMDC portfolio references, repository documentation,
GitHub repository identities, and HQ canonical records.
